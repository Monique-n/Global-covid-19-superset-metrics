# Global COVID-19 Surveillance and metrics Dashboard

An interactive epidemiological surveillance dashboard built using **Apache Superset**, **Docker**, and **PostgreSQL**.

##  Features
- **Key Performance Indicators (KPIs):** Global Cumulative Confirmed Cases, Active Cases, and Total Mortality.
- **Geographic Breakdown:** Bar chart displaying the Top 10 most affected countries by confirmed cases.
- **SQL Data Transformations:** Standardized aggregated metrics using SQL `COALESCE` handling for missing records.

##  Tech Stack
- **Business Intelligence:** Apache Superset
- **Database:** PostgreSQL
- **Containerization:** Docker & Docker Compose
- **Version Control:** Git & GitHub
